# Media: sources and licenses

All media in `media/` are public domain (CC0), designed by the project itself, or created with
ChatGPT for this project. Attribution is not legally required; it is listed here anyway so that
it stays clear where each file comes from.

## Sigil

Created with ChatGPT for this project; the admin of the Discord server designed it in several steps
and picked it (prompts in `PROMPTS.md`, rules in `BRAND.md`). No material from
Bloodborne. `media/brand.py`, `media/logo.html` and `media/og.html` derive from it: the Discord icon,
favicons, logo (`theme/logo.png`, `website/public/logo.png`), the emblem on the website home page
(in two layers, bone and blood: `website/public/emblem-bone.webp`, `website/public/emblem-blood.webp`)
and the preview image (`website/public/og-image.jpg`).

| File | Content |
|---|---|
| `brand/sigil.png` | Sigil: chalice and blade in one shape, crescent moon in blood (original) |
| `brand/sigil-cutout.png` | cut out, generated by `brand.py` |
| `brand/discord-icon.png` | Discord server icon (1024 × 1024), generated by `brand.py` |

Obtained via the Iconify packages `@iconify-json/pinhead` and `@iconify-json/simple-icons` (npm),
whose license information matches the projects.

New icons: put the SVG in `media/icons/` (CC0/public domain only), add the source here and
run `python3 media/build.py`. This generates `flarum/icons.less` (classes `bbicon bbicon-NAME`,
e.g. as a tag icon in the admin) and `website/src/lib/icons.js` (`<Icon name="NAME" />`).
